# SmartStock Pro

Nền tảng Android hỗ trợ nghiên cứu và phân tích cổ phiếu Việt Nam bằng AI.

## Công nghệ
- Mobile: Flutter (Android)
- Backend: Python FastAPI
- Database: PostgreSQL
- AI: LLM + RAG, chạy qua backend; không nhúng API key vào ứng dụng

## Trạng thái
Đang xây dựng nền tảng ban đầu. Backend hiện có API health check; các phân hệ xác thực, dữ liệu thị trường, phân tích, AI và ứng dụng Flutter sẽ được triển khai theo từng giai đoạn.
