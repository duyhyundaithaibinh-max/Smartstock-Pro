## Explicit limits / remaining gaps

- The migration tests use SQLite fixtures and injected authorizer failures. They do not prove a production database upgrade, backup/restore procedure, multi-process or multi-host migration race, or operational rollback on deployed data.
- Backend API tests and Android widget tests do not constitute a live Android-to-Backend end-to-end test.
- Market-data tests cover the named validation/import/report/detail/chart cases; they do not prove a live market-data provider or every possible OHLCV source.
- The interpretation guard and disabled model gateway tests establish guardrails, not an operational AI model integration. No paid AI provider/SDK is introduced here.
- Physical Android, real Save As provider, LAN/TLS/firewall, backup/restore, release signing and production deployment remain NOT TESTED.

## Scope guard

No API route/schema change, no VPS adapter/API/dependency, no synthetic market data, no paid AI provider or SDK, and no new runtime dependency is part of this follow-up. Deterministic analysis and AI interpretation remain separate; no live AI inference is claimed.
